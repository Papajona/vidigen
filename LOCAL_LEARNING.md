# Local learning design

Vidigen's local learning system is a preference/retrieval layer, not automatic retraining of a foundation video model. It can analyze requests, classify the requested workflow, extract style tags, retrieve high-rated prompt patterns, and construct a new prompt.

A future Resource Library can import user-provided/licensed code samples, workflows, images, videos and metadata. It should keep provenance and license metadata and never silently scrape arbitrary websites.
